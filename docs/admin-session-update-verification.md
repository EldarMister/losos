# Сохранение входа и обновление приложения

- Выбранный город сохраняется отдельно в `nakta-admin-region` и восстанавливается до открытия рабочей области. Сохранение начинается после проверки города по загруженному списку, чтобы начальный Бишкек не перезаписал выбор. В браузере с тестовыми ответами API проверены Ош после reload, закрытия вкладки и нового браузерного контекста с сохранённым хранилищем; удалённый город заменяется первым доступным. Линтер и production build прошли.

- 16 тестов сессии/уведомлений проверяют перенос из старой вкладки, закрытие вкладки, блокировку хранилища, выход старой сессии при более новом входе, активацию worker, резервный reload, отсутствие повторных reload и очистку обработчиков.
- 11 проверок HTTP + PostgreSQL прошли в изолированной локальной схеме: 30 дней, продление действующей старой сессии, отсутствие записи при частых проверках, отказ для истёкшей сессии, отзыв доступа, выход и блокировка.
- В браузере вошли, закрыли вкладку и открыли новую: пароль повторно не требовался. Повторное открытие с сохранённым состоянием браузера тоже сохраняет вход.
- Тестовый worker намеренно игнорировал `ACTIVATE_UPDATE`. При несохранённой форме «Нет» сохранило изменения. После подтверждения fallback перезагрузил панель примерно за 3,7 секунды, без повторного системного предупреждения и повторного входа.
- Выход в одной вкладке открыл форму входа в обеих вкладках; сервер подтвердил завершение сессии HTTP 200.
- Проверки используют только localhost и тестовую PostgreSQL. Временный тестовый worker удалён. Снимок подтверждения: `screenshots/admin-update-confirmation.png`.
