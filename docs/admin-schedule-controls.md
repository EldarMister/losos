# Элементы расписания админки

«Круглосуточно» использует `Switch` из установленного шаблона, с явной связью подписи и переключателя. Он сохраняет прежнее поле `deliveryIs24Hours`; при включении поля начала и окончания работы отключаются, при выключении становятся доступны.

Выбранные рабочие дни используют основной вариант кнопки: тёмный фон со светлым текстом в светлой теме, светлый фон с тёмным текстом в тёмной. Кнопки содержат только названия дней, без галочек. Невыбранные дни имеют контур, `aria-pressed` сообщает состояние. Размеры кнопок сохраняются при переключении.

Проверено в локальной админке с PostgreSQL: выключение/включение переключателя мышью и клавишей пробела, доступность полей времени, сохранение смешанного набора дней и режима 24/7 с повторной загрузкой. Исходное тестовое расписание восстановлено. На ширине 335 px горизонтальной прокрутки нет. Production build и ESLint прошли.
