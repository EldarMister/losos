# Языки, навигация и профиль

- Русский, кыргызский, узбекский (латиница), английский и казахский доступны через кнопку языка в шапке и на входе. Переведены рабочие экраны, формы, статусы, подтверждения, подсказки и уведомления. Названия блюд, городов, имена клиентов и другие введённые данные сохраняются в исходном виде.
- Первый запуск использует первый поддерживаемый язык из языков браузера/системы. Для остальных языков используется русский. Ручной выбор хранится в `nakta-admin-language`; в меню показаны только пять языков. Изменения синхронизируются между вкладками. Переключение языка не закрывает редакторы и не очищает поля.
- Календарь, даты и числа используют выбранный язык; расчёт периодов по-прежнему ведётся в часовом поясе Бишкека. Валюта остаётся кыргызским сомом.
- Меню на ПК уменьшено с 256 до 232 px, мобильное меню — до 240 px с ограничением для узких экранов. Поиск на телефоне занимает отдельную строку.
- Фактическая ширина проверена в браузере: 232 px на ПК и 240 px на телефоне. Все названия разделов на казахском помещаются на экране 320 px; поиск занимает 358 px на экране 390 px.
- Текущий пароль, заполненный менеджером паролей, не делает профиль изменённым. Введённый новый пароль по-прежнему защищён от потери при выходе.

Проверки: production build и линтер; 19 тестов переводов, сессий и уведомлений. Тесты словарей проверяют все статические сообщения и сохранение параметров подстановки. В локальном браузере с тестовым API проверены все пять языков, автоматический выбор английского и кыргызского, русский для неподдерживаемой локали, сохранённый английский при системном кыргызском, календарь на английском, сохранение введённого пароля при смене языка, выход при заполненном текущем пароле без предупреждения и защита действительно изменённого нового пароля. Ошибок JavaScript не обнаружено.
