# Контакты сайта

Настройки → Контакты сайта: телефон, email, адрес и Instagram. Общие значения по умолчанию: `0505614614`, `naktasushi@gmail.com`, «Ош, ул. Алиева, 104», `naktasushi_osh`.

«Общие для всех городов» задаёт значения для городов без собственных настроек. Выбор конкретного города и отключение «Использовать общие данные» создаёт отдельный набор контактов. Включение этого переключателя и сохранение возвращает город к общим данным. Изменение общих данных сохраняет индивидуальные настройки других городов.

Данные хранятся в `site_contact_settings`; миграция `1785014000000-AddSiteContacts` добавлена в оба списка миграций. `GET /api/site-settings?region=osh` возвращает публичные контакты доступного города. Закрытые `GET/PATCH /api/admin/site-settings` требуют соответственно `settings.view` и `settings.edit`, изменения попадают в аудит. Строка настроек блокируется на время изменения, чтобы параллельные сохранения разных городов не перезаписывали друг друга.

Подвал и страница поддержки используют эти данные. Подвал обновляет контакты при выборе города, возвращении на вкладку, сигнале сохранения в соседней вкладке и раз в 45 секунд. Email в правовых документах и общие контакты организации для поисковиков также используют общие настройки. Прежние поля телефонов кухни в настройках города остаются отдельными.

Публичный блок ИП сокращён: убраны ИНН, регистрационный номер и повторение реквизитов в подвале. ФИО и исходный адрес оператора сохранены в разделе «Правовая информация», на который ссылается политика; адрес ресторана не выдаётся за новый адрес регистрации ИП.

Выбор города не открывается до ответа сервера, при единственном доступном городе, при пустом списке и ошибке загрузки. Неактивные города и дубликаты не участвуют в выборе.

Проверки: сборка сайта и API, линтер изменённых компонентов, тесты переводов; `npm --prefix server run test:site-contacts` проверяет реальные HTTP-маршруты, разрешения, валидацию, миграцию, сохранение и наследование через встроенный PostgreSQL PGlite. В изолированной браузерной копии проверены подвал при ширине 390 px и на компьютере, автоматический выбор единственного Оша, сохранение индивидуального адреса, его появление на сайте и возврат к общим данным. Рабочая база при этих проверках не использовалась.
